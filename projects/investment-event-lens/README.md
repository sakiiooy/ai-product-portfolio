# 事件透镜 · Investment Event Lens

投资事件情报与证据时间线的产品设计及可操作合成演示。围绕同一事件的传闻、回应、框架协议、更正和终止，展示事实变化、证据冲突、历史视图与标的关系。

这是个人产品设计作品，面向同花顺投资者的使用场景；并非同花顺官方产品或已接入生产数据的服务。

## 内容

- [完整产品设计与验收方案](同花顺事件透镜_产品设计.md)：用户任务、主链路、证据模型、状态与时间规则、MVP 和验收边界。
- [合成交互演示](index.html)：单个 HTML 文件，内置 CSS、JavaScript 和固定合成数据，无外部资源依赖。
- [文件清单](MANIFEST.json)：发布副本的大小与 SHA-256。

## 打开演示

下载仓库后，使用现代浏览器打开 `index.html`。也可在仓库目录运行：

```sh
python3 -m http.server 8000
```

随后访问 `http://localhost:8000`。GitHub 的文件页只显示源码；下载打开或使用静态托管后才能操作。

可切换历史时点、证据材料与演示异常，检查更正后的旧依据、否认范围及资料过期提示。演示不请求外部接口，也不会保存个人数据。

## 实现与验证边界

现有内容完成于 2026-11-19，本公开副本整理于 2026-11-20。产品设计正文保留原交付时的验证和发布范围；公开整理只增加本 README、文件清单和 HTML 标准文档外壳。

演示全部为合成案例，不代表真实公司、实际交易或投资建议。未接入扶摇、iFinD、在线大模型或真实金融数据；未实现生产级采集、自动聚类、后台事件引擎、实时监控或账户系统。

原交付记录中的浏览器检查覆盖固定案例、历史证据隔离、金额更正、异常提示和窄屏布局；不证明真实数据端到端能力。本次整理复核了文件完整性、外部依赖和公开内容边界，没有重复宣称新的生产验收结果。

## AI 角色与数据

AI 用于产品设计初稿、方案交叉检查及演示实现；确定性前端逻辑驱动合成场景切换。官方接口文档仅用于可行性参考，链接及能力边界见完整设计稿。所有公开内容均为设计与演示材料。
