# 澄策 自然语言选股与策略解释器

这是一个可运行的研究辅助 Web MVP：自然语言意图 → 澄清与可编辑条件 → 用户确认 → 确定性筛选 → 每股证据解释 → 同快照条件影响比较 → 比较、保存和导出。

当前产品使用 6 只 A 股的 **2024 年度官方年报历史样本**，有真实原文、原始金额和披露同比值。它不是实时行情产品，也不覆盖全 A 股。PE TTM 与 60 日波动率未取得可核验数据，保持 `null`。

## 启动

需要 Node.js 20 或更高版本，不依赖 npm 包，不需要数据库。

```sh
npm run dev
# http://127.0.0.1:4173
```

也可直接 `node scripts/dev.mjs`。`PORT` 可调整本地端口。开发服务器启动时构建一次，修改源文件后请重启。

```sh
npm run build
npm test
```

先 build 再 test：API 测试针对当前构建出的 Worker。`dist/server/index.js` 是可部署到 Cloudflare Worker 的 ES module，默认导出 `{ fetch }`，包含全部页面资产和固定数据快照。本公开副本不包含 Sites 项目配置；部署到自己的平台时请自行配置目标。

## 一分钟体验

1. 保留默认意图“经营改善，营收和归母净利同比至少5%”，检查两项条件并勾选确认，执行后为 **3 入选、3 排除**。
2. 将营业收入同比阈值从 5 改为 4。影响预览显示 **3 → 4 入选，新增海尔智家**；确认执行后更新正式结果。
3. 点击“合理估值与稳定走势”。核验启用条件后执行为 **0 入选、3 排除、3 待核验**。PE、波动缺失不会补成零，也不会进入入选。
4. 打开任一股票“逐条核验”，检查实际值、阈值、原始字段、本期/上期金额、单位、披露日、年报原文和页码。
5. 勾选 2–3 只进行比较；保存策略后在“我的策略”恢复，或导出 JSON / CSV。

这些结果描述的是固定样本和所列阈值，不能外推为投资推荐或未来表现。

## 产品选择和职责

- **语言层**只生成规则草案、问题和假设；不能创造股票数据或判断入选。
- **规则层**只接受 4 个白名单字段、5 种比较符和有限数值，识别互相矛盾的上下界。MVP 支持 AND；OR、否定和未支持单位会要求澄清。用户可明确放弃未支持表达，仅以编辑器中的条件为准。
- **金融数据层**提供固定官方披露证据；未来实时适配器必须验证 HTTP 与业务 `code`、字段、单位和可用时点后才允许入库。本版没有伪装成已接通的扶摇或 iFinD 数据接口。
- **筛选引擎**逐条比较。AND 任一已知 FAIL 则排除；否则任一 UNKNOWN 则待核验；只有全部 PASS 才入选。质量状态为缺失、失败、冲突、过期、样本不足等即使有数值也返回 UNKNOWN。
- **解释层**展示确定性检查及原始证据；不生成综合荐股分或确定性预测。

## AI 与环境变量

当前部署不需要密钥即可运行，页面明确显示 **本地词典解析，未调用大模型**。词典仅支持有限表达，不能宣称理解任意投资意图。

可选服务端接入采用 OpenAI Responses API 与严格 JSON Schema。部署者需通过托管平台的 Secret 设置以下两个值，任一未配置均使用词典：

| 变量 | 作用 |
| --- | --- |
| `OPENAI_API_KEY` | 仅服务端使用的模型 API 密钥 |
| `OPENAI_MODEL` | 账号实际可用且支持 Structured Outputs 的模型 ID，必须显式配置 |
| `FUYAO_API_KEY` | 后续金融数据适配器预留变量；本版本不读取、不调用 |

不要把密钥写入浏览器、源码、Git、命令参数或 `.openai/hosting.json`。`.env.example` 只有空值占位；开发服务器读取进程环境，不自动读取 `.env`。本次没有配置、获取或测试真实模型密钥。

模型调用超时、HTTP 错误、非 JSON、非法字段、空结果都会显式降级词典。模型即使已配置，也不能绕过本地合规与数据范围门。官方 API 契约参考：[Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)。

## 数据与复现

`data/evidence.json` 保存 6 只股票的披露字段。样本：美的集团、海尔智家、贵州茅台、比亚迪、格力电器、伊利股份。财务报告期为 2024-12-31；资料快照日期 2025-04-30；采集发生于 2026-11-19。披露日只有日期精度，精确 `available_at` 为 `null`，**不支持历史可交易回测**。

构建生成源数据 JSON 内容的 SHA256；页面、导出和保存策略关联该校验值和 `annual-2024-v1` 快照编号。比较保持快照及内容不变，只修改规则。筛选按年报披露的两位小数同比值执行，原始金额仅辅助复核，避免由四舍五入推导不同边界。

重要口径：美的营业收入采用主要会计数据表的 9.44%，不能与“营业总收入 9.5%”混用；海尔 2023 年对比采用年报调整后金额。其余数据核验和原文见 `data/data-notes.md`、每股证据页及 `data/evidence.json`。

## 数据异常与本地状态

初次数据加载失败禁止筛选。页面已完整加载历史快照后，筛选请求发生网络错误或超时时，可用同一快照本地计算，并明确显示本地快照模式，绝不表示数据刷新。服务端返回的快照不匹配或条件校验错误不会用本地计算绕过。

策略仅保存在此浏览器 localStorage，不跨设备同步、不创建账户。存储失败显示导出兜底；清除浏览器会丢失本地策略。导出 CSV 包含结果、规则 JSON、快照校验值、执行时点、执行方式和原文 URL。原文链接在外部打开，不下载用户数据。
