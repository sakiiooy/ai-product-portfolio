# 测试说明

本版本使用 Node.js 自带 test runner。先运行 `node scripts/build.mjs`，再运行 `node --test tests/*.test.mjs`。当前自动化回归共 **38 项全部通过**；浏览器实测由交付记录补充，不能把单元测试当作真实金融接口或真实模型连通证明。

| 范围 | 已覆盖检查 | 预期 |
| --- | --- | --- |
| 真实主链路 | 6 股默认营业收入及归母净利同比≥5% | 3 入选、3 排除 |
| 条件敏感性 | 固定快照中仅将营业收入5降4 | 海尔智家加入，4 入选、2 排除 |
| 数据缺失 | 加入合理估值与稳定走势 | 0 入选、3 排除、3 待核验 |
| 三值逻辑 | FAIL + UNKNOWN、PASS + UNKNOWN | 分别为 FAIL、UNKNOWN |
| 异常质量 | missing/error/unavailable/insufficient/stale/conflict | 有数值也为 UNKNOWN |
| 数值边界 | null、0、NaN、Infinity、字符串、空规则 | null与异常不补0；0可比较；空规则阻断 |
| 条件冲突 | 不可同时满足的严格/非严格上下界 | 阻止执行 |

| 构建资产 | 内嵌后app.js与源码逐字一致 | 特殊替换序列不破坏脚本 |
| 证据导出 | screen带执行时点、hash与原文URL | 核心结论可追溯 |

## 浏览器验收清单

- 默认财务条件确认执行，逐条证据与真实年报一致。
- 修改阈值后，影响预览正确；正式结果在再次确认执行后更新。
- 缺失字段加入后正确进入待核验，不生成零值。
- 排除页继续显示已知失败和其他缺失项。
- 最多3股比较；2股以上才允许打开比较窗口。
- 保存、恢复、JSON和CSV导出；恢复不残留旧结果。
- 矛盾条件禁用执行；澄清必须明确解决；合规阻断不可通过手工澄清按钮绕过。
- 数据页显示报告期、资料快照、采集时点、内容校验值和未实现能力。
- 移动屏幕无主体横向溢出，表格可局部滚动；键盘可关闭弹层并返回焦点。

## 仍未验证或未实现

真实 OpenAI 模型调用与扶摇/iFinD接口连通尚未验证，也未配置相关生产密钥。未实现收益回测、实时数据更新、后台监控、交易执行或跨设备持久化。实际金融数据缺失值为null；为验证异常而构造的数据仅存在测试代码中。
