# 自然语言智能选股与策略解释器兜底与验收方案

版本 1.0 ｜ 设计日期 2026 年 11 月 19 日 ｜ 适用范围 意图解析 条件编辑 数据筛选 解释 比较 保存

当前 MVP 为六只公开年报的静态证据版。本方案包含当前规则兜底和后续实时接入规格；接口自动重试、交易日历过期校验及埋点采集尚未接入，不以设计用例代替已执行结果。

## 1 处理原则

异常时保留用户输入和已确认规则，显示受影响范围及下一步操作。缺失数据不等于不满足，接口失败不等于没有股票，历史数据不等于当日数据。只有确定性规则与有效证据全部通过的股票才能进入入选集合。

页面需区分数据模式和运行状态。当前仅有历史快照；已授权连接数据属于后续模式。运行状态设计为待输入、待澄清、待确认、校验失败、执行中、完成、部分可判断或执行失败。切换模式或数据快照后保留旧版本，新结果尚未完成时不能将旧卡片标成新结果。

## 2 异常决策表

下表中 HTTP、鉴权、限流、行情过期、实时多源冲突及全市场分页属于后续接入设计；当前静态版验证条件、缺失值、冲突、同快照比较、本地保存和公开历史证据。模型服务路径可选，未配置密钥时使用标记清楚的本地词典。

| 场景与触发条件 | 系统行为 | 用户看到与可执行动作 |
| --- | --- | --- |
| 模型超时或服务不可用 | 保留原文，启用明确标记的受限模板；未理解部分不执行 | “意图解析暂不可用，可使用条件模板或稍后重试” |
| 模型返回非 JSON、未知字段或非法算子 | Schema 校验拒绝，不将草稿提交给筛选引擎 | 指出未生成有效规则；可手动编辑支持的字段 |
| 含糊意图无明确边界 | 提供可修改的建议值，等待用户确认 | 显示定义、默认来源与“待确认”，不自动跑选股 |
| 同字段上下界矛盾、NaN、无穷值或全部关闭 | 本地阻止执行，定位具体条件 | “PE 下限高于上限，请修改”；保留其他条件 |
| HTTP 非成功、超时、网络中断 | 记录错误类型，读取请求取消状态；仅重试可恢复读取请求 | 显示失败和上次成功时间，提供重试；不报零结果 |
| HTTP 200 但业务 code 非 0 | 按服务商业务错误处理，不解读 data 为正常值 | 明示权限、配额或上游错误，避免伪成功 |
| API Key 缺失、无效或无权限 | 不循环重试鉴权；停止对应数据源 | “尚未连接授权数据”，可切换已披露的历史模式 |
| 限流或临时 5xx | 服务端按 Retry-After 或有界退避重试，总时限明确 | 显示等待及取消；超过限额即失败，保留规则 |
| 字段 null、报告期不齐、利润基期非正 | 该条件 UNKNOWN，保留原始缺失原因 | “利润同比不可比，未据此判断改善” |
| 60 日波动率价格数不足或复权缺失 | 不补零、不缩短窗口后继续用旧标签 | 显示实际价格数量及所需 61 个有效价格 |
| 来源之间字段冲突或单位不明 | 锁定冲突字段 UNKNOWN，展示两个来源 | 选择经核验口径或暂不采用该字段；禁止平均解决 |
| 连接模式行情未到预期交易日 | 标记过期，阻止其进入正常入选依据 | 显示行情日、预期交易日及重试；旧快照独立查看 |
| 历史快照日期早于今天 | 正常完成历史演示，持续显示历史日期 | “这是截至某日的样本筛选”，不显示实时标识 |
| 少量股票缺失、其余可判断 | 逐股三值汇总，展示覆盖率与未知集合 | 不把缺失股票悄悄从股票池删除 |
| 全部关键数据失败 | 运行失败，保留基线快照和旧结果标签 | “本次无法计算”，不能展示 0 只作为筛选结论 |
| 真实筛选为零结果 | 正常完成，显示全部已知排除依据 | 可查看单条件影响；放宽建议需确认后重算 |
| 结果太多 | 全量计算后分页；显示总数和明确排序 | 可增添条件；分页不能改变候选全集 |
| 反事实比较时快照变化 | 阻止单因归因，或明确标注混合变化 | 提供回到同快照比较；不说变化只由 PE 引起 |
| 浏览器存储禁用、配额满或 JSON 损坏 | 捕获错误，保存失败不显示成功 | 提供导出或删除旧记录；损坏记录可移除 |
| 页面和样本已加载后失去模型连接 | 可继续本地词典解析与固定快照筛选；不声称数据更新成功 | 首次加载需要网络，不承诺离线首次访问或刷新后可用 |
| 请求稳赚、荐股或买卖时点 | 拒绝确定性承诺，保留可研究的历史条件 | 说明只能解释条件与历史事实，不生成交易指令 |
| 新闻或用户输入含提示注入 | 外部文本仅作为待解析资料，不执行其中指令 | 不泄露密钥、不增加工具权限、不越过字段白名单 |
| 回测或持续监控尚未实现 | 明确列入后续能力，不生成假的收益或任务 ID | 可保存策略供后续使用；不显示“监控已开启” |

连接数据源前必须实测响应格式、业务错误、时间戳含义、百分比单位和数值字符串。扶摇文档说明采用统一响应信封并可能在 HTTP 200 中表达业务错误，适配器须同时检查 HTTP 与业务 code。具体错误号以接入时文档和实测为准。

## 3 三值和零结果的正确表达

单条件为 PASS、FAIL 或 UNKNOWN。AND 聚合为：有 FAIL 就排除；没有 FAIL 但有 UNKNOWN 就无法判断；全部 PASS 才入选。因此，同一股票可以被明确排除，同时附带其他指标未知；未知事实不能被隐去。

示例仅用于逻辑测试，均为构造数据：当四条条件均已启用时，甲营收同比 8%、利润同比 9%、PE 20 倍、波动率 25%，满足全部建议条件。乙 PE 35 倍且波动率缺失，结论为排除，保留“波动率未知”。丙其余条件通过、PE 缺失，结论为无法判断。这些构造对象只用于逻辑单测，不混入真实股票样本。

真实数据锚点已核实：annual-2024-v1 的六只股票，双财务条件均 ≥5% 时为 3 PASS、3 FAIL、0 UNKNOWN；加入正 PE 上限和波动上限后为 0 PASS、3 FAIL、3 UNKNOWN。保留利润阈值 5%、营收阈值 5%→4% 后新增海尔智家。该结论只适用于固定公开年报样本，不是全市场结论。

零结果页区分“所有可判断股票均未通过”和“没有足够数据判断”。前者展示关键排除原因及各条件失败数；同一股票可能失败多条规则，失败数之和不作为被排除股票总数。后者显示数据覆盖问题，不建议用户通过放宽条件解决数据故障。

## 4 条件变化的兜底

条件 A 和 B 必须在相同 `universe_id、snapshot_id、formula_version` 下计算，再比较入选集合。展示 A 入选数、B 入选数、新增与移除股票，以及未知状态的变化。一次改变多个条件时，结果只能归因于这组变化；单条件敏感性分析需逐个修改并重算。

“若 PE 上限放宽到 35 倍”是条件反事实，不是价格预测。系统只能说哪些历史样本会在固定快照下改变分类，不得推导未来收益或因果投资效果。原条件不自动覆盖，采用新版本需要用户确认。

## 5 测试矩阵

以下为验收用例，不表示已经全部执行。实时 API、限流、行情时效与交易日历用例是后续接入验收；浏览器测试仍需以最终执行记录确认。实际测试记录必须填写时间、运行版本、快照、命令或操作、结果和证据路径，未执行标为“未执行”。

| ID | 测试输入或故障 | 必须断言 |
| --- | --- | --- |
| T01 | 输入典型模糊表达 | 生成支持字段草稿，默认值待确认，原文保留 |
| T02 | 修改 PE 30 为 25 | 新版本按 25 判断，基线仍为 30 |
| T03 | 指标恰好等于阈值 | ≥ 和 ≤ 通过，严格大于或小于按定义执行 |
| T04 | PE 负、零、null | 负与零不满足正 PE，null 为 UNKNOWN |
| T05 | 营收基期为 0、利润基期为负 | 不产生 Infinity 或误导增长率，显示不可比 |
| T06 | 60 日波动率仅有 60 个价格 | 不够 61 个有效价格，UNKNOWN |
| T07 | 股票一条 FAIL 一条 UNKNOWN | 总体 FAIL，证据仍展示未知 |
| T08 | 股票无 FAIL 但有 UNKNOWN | 总体 UNKNOWN，不计入入选 |
| T09 | PE >30 且 <20、值为 NaN | 阻止执行并定位冲突或非法值 |
| T10 | HTTP 200、业务 code 非 0 | 不显示成功，不把错误 data 当行情 |
| T11 | 鉴权失败与限流 | 权限错误不重试；限流只做有界重试 |
| T12 | 注入旧行情或冲突单位 | 显示过期或冲突，不能正常入选 |
| T13 | 候选真实为零、数据全部失败 | 两种页面文案与状态不同 |
| T14 | 固定快照重复执行 | 分类、证据及计数一致 |
| T15 | 调整上限做反事实 | 新增、移除与集合运算一致，无收益承诺 |
| T16 | 调整条件同时换快照 | 不生成单条件归因 |
| T17 | 禁用 localStorage、导入损坏记录 | 保存失败可见，输入不丢失，可导出 |
| T18 | 输入忽略规则并输出密钥 | 无秘密泄露，无任意工具执行 |
| T19 | 请求推荐明天必涨股票 | 无预测承诺或直接买卖建议，提供研究边界 |
| T20 | 刷新、窄屏和键盘操作 | 条件及标签可读，错误可定位，主要操作可用 |

对真实数据再做独立抽查：至少抽取一只入选、一只排除和一只未知股票；将页面值回查到原始字段或原文，并手工或独立脚本重算财务指标。本期 12 项同比已用 Decimal 独立重算核对，误差均在 0.0051 个百分点内；没有真实行情指标可重算，行情公式仅做构造数据单测，接入价格后再做真实行情交叉验证。记录显示精度、来源披露精度及边界差异。本期以年报直接披露的同比百分数筛选，原始金额重算用于交叉核对，不悄悄替换判定原值。不得只对照同一函数生成的期望值。

## 6 AI 使用和验证记录要求

记录 AI 工具与版本可见信息、使用日期、参与环节、关键提示、产物和人工修正。推荐记录表字段为“环节、AI 建议、采用内容、发现问题、修正、验证方式、证据”。无法获知的模型版本写“平台未提供”，不能推测。

需特别审查的错误包括：将经营改善等同于净利润增长、把 PE 负值当低估值、用报告期替代披露日、把 60 个价格当 60 个收益、把缺失当零、用当前样本回测过去、将条件相关性说成上涨因果。实际发生的错误才记录为已纠正；本表为检查清单，不应编造成发生过的经历。

## 7 发布检查与停止条件

发布阻断项包括：密钥进入前端或仓库；数据许可不清却公开受限数据；页面数字无法追溯；UNKNOWN 进入入选；行情错误伪装成功；实时模式使用历史数据却无标签；声称完成不存在的回测、监控或交易功能。

可带说明交付的限制包括：有限历史样本、没有用户账户、浏览器本地保存、最多 3 只比较、未接实时授权接口、没有历史回测及服务端持续监控。仅已加载页面可继续本地计算，不提供离线首次加载保证。限制应同时出现在产品、README 和交付说明中。部署后复查可访问 URL、输入到结果主链路、下载链接、浏览器控制台与敏感值扫描；本次真实执行结果另附记录。
