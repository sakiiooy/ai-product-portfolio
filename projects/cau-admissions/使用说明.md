# CAU 硕士申请 · Joy 三意图交互 Demo

## 打开方式
双击 `CAU硕士申请-三意图交互Demo.html`，用现代浏览器打开即可。所有CSS、脚本、模板和样例均已内嵌，无需安装依赖或连接网络。若浏览器不支持剪贴板，可在弹窗中手动复制或下载。

## 建议体验顺序
1. **面试进度查询 GUI**：查看阶段与日程 → 刷新模拟进度 → 查看模拟来源。查询时间和业务更新时间分别展示。
2. **面试改期 CUI**：开始准备 → 选择明确KST时段 → 核对原时间、新时间、北京时间 → 明确确认模拟提交 → 右侧「演示控制」模拟招生方批准并核验 → 返回GUI查看同步后的日程。
3. **长时间无进展 CUI**：载入「面试后12天」独立样例 → 开启本地提醒或准备催询草稿 → 编辑并明确确认当前版本 → 分别模拟发送、渠道送达、招生方受理。
4. **异常兜底**：每个意图的第5条样例；也可在「演示控制」切换查询失败、没有时段、时段冲突、日历部分写入、发送失败。重试不自动重复提交；部分写入可转人工对账并模拟回滚。
5. **设计资产**：Prompt模板可复制，15条话术可独立运行，演示记录和结构化样例可下载。导航切换保留当前业务记录；载入独立样例会明确重置本地演示。

## 文件说明
- `Prompt模板与话术样例.md`：统一角色设定与三个子模板；含输入变量、约束、禁止清单、动作枚举、JSON输出格式；每个场景5条话术，含1条兜底。
- `content.json`：相同内容的结构化版本。
- `source/`：可编辑HTML/CSS/JS源码及纯逻辑回归脚本，`python3 build.py`可重建`dist/index.html`。
- `交互验收记录.md`：实际执行的检查与覆盖范围。
- 三张JPG：浏览器实测页面截图。

## 演示边界
CAU指韩国中央大学（Chung-Ang University），仅作为情境背景。虚拟申请人、申请、专业、批次、日期、审批、时段和回执均为mock；固定时钟为2026-10-25 10:00 KST。页面使用确定性本地脚本，未调用大模型、CAU真实系统、邮件或日历。7日阈值为演示参数；没有更新不能推断拒录，也不承诺校方回复期限。
