候选人信息真空 · 4 个待验证节点

定义：一个等待区间内，没有收到新的、经确认的进度或下一步信息。

! V2

排期等待无有效安排

I2
待验证假设 · 低置信
缺少信息
候选人收不到有效面试时间、方式、准备事项或改期确认。
可能原因
双方日历、IM与ATS分离；改期后的通知与确认责任不清。
可能后果
候选人无法安排时间，反复追问；可能错过面试或放弃流程。
Agent 介入
在授权范围内协商并同步有效日程，追踪双方确认；无法确定时告知候选人当前状态与下次更新时间。
! V3

面试结束后无进展

I5
待验证假设 · 低置信
缺少信息
候选人面试后收不到处理状态、下一步或下次更新时间。
可能原因
评价迟交、口头反馈未入库；HR等待内部反馈，却未触发对外更新。
可能后果
候选人无法判断是否仍在流程中，增加焦虑与追问，也可能接受其他机会。
Agent 介入
追踪缺失评价与超时责任人；按HR批准状态更新候选人，不将尚未评价解释为未通过，不外发内部评价。
! V4

决策或暂停后无更新

I6
待验证假设 · 低置信
缺少信息
候选人收不到流程仍在评估、需要补评或已经暂停的获批状态，以及下一次更新时间。
可能原因
复盘分歧未解决；人工决策或暂停责任不明；内部状态未转为候选人可接收的通知。
可能后果
候选人持续等待并误判进度；HR反复解释，面试官多轮讨论仍难收口。
Agent 介入
明确人工责任人与期限，追踪补充任务并升级超时；依据已确认状态对外更新，不泄露内部争议，不自主决定录用或淘汰。
! V6

入职或关闭缺少交接信息

I7
待验证假设 · 低置信
缺少信息
候选人收不到获批结果后的入职步骤、联系责任人，或流程已关闭的明确通知。
可能原因
招聘与入职交接分散；关闭任务被视为内部操作；面试官、HR及后续责任人的通知职责未明确。
可能后果
候选人继续追问或错过必要准备；面试官收到职责外咨询，HR重复补发信息。
Agent 介入
依据人工确认且可对外发布的结果，起草通知和交接清单，追踪责任人确认；不自行承诺录用、薪酬或未确认期限。

流程与 Agent 能力边界

面试官不默认等于用人经理或最终决策人；多轮面试复用 I2–I6。I7 仅承接明确指派的后续职责。

固定触发条件下的回执、提醒、模板通知与排期优先由 ATS / 规则承担。Agent 增量假设：理解上下文、识别矛盾与阻塞、协调例外、核验结果。录用、淘汰、Offer 条件及对外承诺由授权人员确认。

三方检查：HR 看流程与责任；面试官看本人任务与证据；候选人看获批状态、下一步、更新时间和联系入口。内部评价不自动对外发布。
